# Learning Objectives
•	Translate recursive algorithms into recurrence equations.
•	Solve simple recurrences by expansion/substitution.
•	Apply the Master Theorem when its conditions hold.
•	Interpret n^(log_b a) correctly as n raised to the power log_b(a).
•	Validate recurrence predictions using counters or runtime experiments
